# AGENTS.md

Instructions for AI coding agents working on blackbox_exporter.

Rules that apply to both humans and agents are in [CONTRIBUTING.md](CONTRIBUTING.md).

* Read [CONTRIBUTING.md](CONTRIBUTING.md) in full before you change anything, and follow it over instead of the default behavior.
* Also read the [Prometheus contributor's guide](https://prometheus.io/docs/guides/contributing/#contributors-guide) and [security policy](https://prometheus.io/docs/operating/security/) in full before you plan out changes or do any security related work.
* AI agents should NOT post comments, replies or reviews on issues and pull requests, discussion on issues and pull requests are between humans.
